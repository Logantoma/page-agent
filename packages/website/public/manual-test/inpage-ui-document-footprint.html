PsySquid 网页交互足迹 — 引导式人工测试

不用打开 DevTools。按下面 5 个步骤操作即可；页面会站在普通网站 JavaScript 的视角，自动记录焦点、事件传播和 DOM 注入。最后点击“复制最终报告”，把整段文本原样发给远端 AI。

测试目的：确认 PsySquid 的正常网页交互足迹和 P1 自动抢焦点修复。此页用于兼容性审计，不用于规避或绕过网站安全机制。
