B4.5 网页自身打开新标签页

这是通用网页导航回归页。目标是验证页面自身通过 target="_blank" 和 window.open() 打开的新标签页，Agent 是否能自动发现、切换、读取信息并返回原页。

测试时必须点击页面提供的链接/按钮打开新标签页；不要使用 Agent 的 open_new_tab 工具绕过网页行为。
  1. 点击“打开合同附件（target=_blank）”，在新标签页读取合同校验码，然后切回本页。
  2. 点击“打开供应商详情（window.open）”，在新标签页读取供应商校验码，然后切回本页。
  3. 分别填入两个校验码并提交。页面显示 PASS 才算完成。
