PsySquid Panel Focus Preservation Test

用于验证 PsySquid Web 的 in-page Panel 不会在初始化或 Agent 完成时自动抢走网页输入焦点。页面不会主动改变焦点，除非你点击“重置结果”按钮。

实时判定

网页输入框连续持有焦点0 ms
检测到非主动的 Panel 抢焦点次数0
尚未检测到异常。请先点击网页 Input 或 Textarea 开始测试。

建议手测流程

  1. 确认 PsySquid Launcher 已出现，打开 Panel。
  2. 点击上面的“网页原生 Input”，输入 FOCUS-A，等待 1 秒；焦点应保持在网页 Input。
  3. 在 PsySquid Panel 中执行：等待 5 秒，然后告诉我当前页面标题，不要点击或输入网页元素。
  4. Agent 进入 running 后，立即再次点击网页 Input，并持续输入 FOCUS-B-123456。
  5. 等 Agent completed 后再继续敲几个字符。字符必须仍进入网页 Input，且“抢焦点次数”保持 0。
  6. 最后主动点击 PsySquid Panel 输入框并输入文字；主动点击必须仍能正常获得焦点。
